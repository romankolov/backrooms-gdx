The surface textures are not the atlases from the model: those carry the room's lighting baked in and
only about twenty texels to the metre. `tools/extract_vr_assets.py` cuts the largest clean patch of
each material, divides out its own low-frequency light and colour, makes it seamless, and adds
procedural grain so it still holds up at arm's length. The result is reproducible:

```sh
pip install pillow numpy
python3 tools/extract_vr_assets.py            # textures, from backrooms_vr.glb
python3 tools/make_assets.py                  # sounds and icons, from nothing
```
